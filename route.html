How to build the real thing

This demo runs on a synthetic city grid so it works offline. The same idea scales to a real city by swapping the grid for street data.

LayerToolJob

Steps

1. Download the street graph for your city with OSMnx. 2. Join each street segment to canopy, surface temperature and flood layers. 3. Train a model that predicts segment temperature for a given hour and weather. 4. Set each edge’s cost to length plus a heat or rain penalty, and run Dijkstra or A*. 5. Serve it with FastAPI and draw the result in this front end by replacing the grid with a MapLibre map.

Backend sketch (FastAPI + OSMnx)

import osmnx as ox, networkx as nx
from fastapi import FastAPI
app = FastAPI()
G = ox.graph_from_place("Raichur, Karnataka, India", network_type="walk")

def cost(u, v, d, mode, w=1.0, rain=0.0):
    base = d["length"]
    if mode == "cool":
        heat = d.get("pred_temp", 36)       # from your ML model
        shade = d.get("shade", 0)           # 0..1 canopy / cover
        return base * (1 + w * max(0, heat - 30) / 14 * (1 - 0.7 * shade))
    if mode == "rain":
        return base * (1 + rain * (9 * d.get("flood", 0) + 2.2 * (1 - d.get("covered", 0))))
    return base

@app.get("/route")
def route(o_lat: float, o_lon: float, d_lat: float, d_lon: float,
          mode: str = "cool", w: float = 1.0, rain: float = 0.0):
    o = ox.nearest_nodes(G, o_lon, o_lat)
    t = ox.nearest_nodes(G, d_lon, d_lat)
    path = nx.shortest_path(G, o, t, weight=lambda u, v, d: cost(u, v, min(d.values(), key=lambda e: e["length"]), mode, w, rain))
    return {"path": [[G.nodes[n]["y"], G.nodes[n]["x"]] for n in path]}

Run this demo

Save the HTML file as index.html and open it in any browser. No build step or internet is needed except for the font. To host it, upload it to GitHub Pages, Netlify or Vercel.

Note: the demo’s “AI” is a transparent scoring model on synthetic data. Real accuracy depends on the data you feed it.
